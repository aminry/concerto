## Goal
Stand up the repo's first JS/TS workspace + the FIRST TS proto codegen + the transport-agnostic
`DataClient` seam, so `apps/web` (519/520) and `apps/mobile` (508/510) build on one shared client
(decision V8, D10). The README's "shared package extraction" was actually greenfield (no buf, no
codegen, no `DataClient`, no workspace) — this is the foundation.

## Inputs to read before starting
- `tasks/v1.0/PHASE5_PLANNING.md` D10 (buf + connect-es, gRPC-Web binary), D11 (mobile shares only
  `@concerto/client`); `design/17 §3.1/§3.2`.
- `crates/proto/proto/concerto/v1/*.proto` (the canonical protos — codegen input).

## Scope — in
- Root `pnpm-workspace.yaml` (`packages/*`) + root `package.json` (+ `pnpm.onlyBuiltDependencies` for
  the buf/esbuild build scripts).
- `packages/client` (`@concerto/client`): buf v2 + `@bufbuild/protoc-gen-es` codegen
  (`buf.gen.yaml` → `src/gen`, `crates/proto/proto/buf.yaml` module marker) producing protobuf-es
  messages + connect-es service descriptors for all 15 protos. The `DataClient` interface
  (`transport` + `subscribe`), `createConnectWebDataClient` (gRPC-Web BINARY over the Core's
  connect-web bridge, D10), `dataClientFromTransport`, and `createClient` re-export. Vitest tests.

## Scope — out
- `apps/web` SPA + `@concerto/ui` renderer extraction (519). The Connect-Web data-client features
  (HTTP/2 + SSE fallback + AckOffset) (520). Auth/TLS/pairing on the transport (521/522). The native
  transport (`createNativeDataClient`) (510). **Desktop migration onto `@concerto/client`** — deferred
  (desktop stays a standalone pnpm app for now; web 519 is the first consumer — see Handoff).

## Public interface this task locks
- `@concerto/client`: `DataClient`/`createConnectWebDataClient`/`dataClientFromTransport`/`Unsubscribe`
  + the `./gen/concerto/v1/<file>_pb` subpath for generated types/services. gRPC-Web **binary** framing.

## Handoff Notes (filled in when finishing)
- **buf works offline-ish:** `@bufbuild/buf` (npm) provides the CLI; codegen ran via `pnpm generate`
  with `protoc-gen-es` local plugin. Generated `src/gen` IS committed so builds don't need buf; a
  regen-diff CI gate (the Rust interface-snapshot precedent) is a 519/CI follow-up.
- **gRPC-Web binary framing (D10):** avoids the prost-serde snake_case vs connect-es camelCase JSON
  mismatch entirely — no JSON casing config needed.
- **Desktop migration deferred:** `apps/desktop` stays standalone (its own pnpm-lock) to avoid
  destabilizing its CI build now. Folding it into the workspace + refactoring `client.ts` onto
  `createTauriDataClient` (a custom connect `Transport` over Tauri `invoke`) is a follow-up; web (519)
  is the first `@concerto/client` consumer, which is the seam's regression proof.
- 519 next: `apps/web` SPA + `@concerto/ui` extraction + the Playwright UI-E2E/screenshot harness,
  consuming `@concerto/client` + `createConnectWebDataClient`.
