## Goal
Stand up the CI pipeline that runs on every commit. CI must (a) build the workspace on macOS/Windows/Linux, (b) run unit tests, (c) run clippy with `-D warnings`, (d) enforce the dependency license allow-list. After this task, any PR that introduces a GPL/AGPL/SSPL/BSL dependency fails CI.

## Inputs to read before starting
- `design/00_Architecture_Overview.md` §6.1 (CI: GitHub Actions, platform matrix) and §6.11 (licensing posture: only MIT/Apache-2.0/BSD-2/BSD-3/ISC/0BSD; CI enforces via `cargo deny`).
- `tasks/01-cargo-workspace-skeleton.md` → "Handoff Notes" — workspace is set up; crate names locked.

## Scope — in
- Create `.github/workflows/ci.yml` running on push and PR with a job matrix `[macos-latest, ubuntu-latest, windows-latest]`. Each job runs:
  1. `actions/checkout@v4`
  2. Install Rust via `dtolnay/rust-toolchain@stable` (the toolchain file pins the version)
  3. `Swatinem/rust-cache@v2` for build caching
  4. `cargo check --workspace --all-targets`
  5. `cargo clippy --workspace --all-targets -- -D warnings`
  6. `cargo test --workspace --no-fail-fast`
- Create `.github/workflows/deny.yml` running on push and PR (Linux only) with steps:
  1. `actions/checkout@v4`
  2. `EmbarkStudios/cargo-deny-action@v1` with command `check`
- Create `deny.toml` at repo root with:
  - `[licenses]` `allow = ["MIT", "Apache-2.0", "BSD-2-Clause", "BSD-3-Clause", "ISC", "0BSD", "MIT-0", "Unicode-DFS-2016", "Unicode-3.0"]`, `confidence-threshold = 0.93`, `unlicensed = "deny"`, `copyleft = "deny"`.
  - `[bans]` empty in V0.1 (we ban transitively by license; specific crate bans come later).
  - `[advisories]` `vulnerability = "deny"`, `unmaintained = "warn"`, `yanked = "deny"`.
  - `[sources]` `unknown-registry = "deny"`, `unknown-git = "deny"`, `allow-registry = ["https://github.com/rust-lang/crates.io-index"]`.
- Create `.github/workflows/format.yml` running `cargo fmt --all -- --check` on Linux only.
- Create `rustfmt.toml` at repo root with `edition = "2021"`, `max_width = 100`, `imports_granularity = "Crate"`.
- Generate an initial `THIRD_PARTY_LICENSES.md` at repo root via `cargo about generate` (or document the command and check in an empty stub with a comment "regenerated in CI"). Since the workspace is empty, this file may be near-empty — that's fine.
- Update `NOTICE` at repo root if it does not already reference Apache-2.0 transitive-dep attribution (per `design/00 §6.11` — aggregate `NOTICE` + generated `THIRD_PARTY_LICENSES.md`).

## Implementation notes
- Use cached Rust toolchain via `dtolnay/rust-toolchain@stable` with `toolchain` field reading from `rust-toolchain.toml`.
- `cargo deny check` is sensitive to the order of license names; use the SPDX identifier form exactly.
- Windows jobs should set `shell: bash` on every step that uses non-trivial shell, or use `pwsh` consistently.
- Use `fail-fast: false` on the matrix so a Mac failure doesn't cancel the Linux job (helps debugging).
- The `cargo about` tool is optional. If it's heavyweight to set up, defer to Task 53 (release readiness) and just check in a stub `THIRD_PARTY_LICENSES.md` with a `<!-- regenerated by CI; see deny.toml -->` comment.

## Verification
1. `cargo deny check` locally → exits 0 (workspace currently has no third-party deps so this trivially passes; the gate exists for future tasks).
2. `cargo fmt --all -- --check` → no diff.
3. `cargo clippy --workspace --all-targets -- -D warnings` → clean.
4. Push the branch and verify all four GitHub Actions workflows complete green. (If pushing isn't possible in the agent's environment, use `act` locally or document the manual verification step in Handoff Notes.)
5. Introduce a temporary GPL dependency (e.g., add `readline = "0.4"` to a crate's Cargo.toml — readline is GPL); run `cargo deny check`; confirm it fails with a license violation. Remove the temporary dep before committing.

## Handoff Notes (fill in when finishing)
- **Drift from plan:**
  - **`deny.toml` uses cargo-deny v2 schema, not the v1 schema in the task spec.** Installed cargo-deny is 0.19.7; it rejects the v1 fields `unlicensed`, `copyleft`, `vulnerability`, and the v1 enum value `unmaintained = "warn"` (now expects `"all"`/`"workspace"`/`"transitive"`/`"none"`). Intent preserved: the license allow-list and the source registry restrictions are identical to the spec; `version = 2` under `[licenses]` and `[advisories]` denies anything outside the allow-list (replacing `unlicensed`/`copyleft`) and denies vulnerabilities by default (replacing `vulnerability = "deny"`); `yanked = "deny"` is kept; `unmaintained` is left at its default to avoid pinning to one of the new enum values without need. The local GPL-rejection test (step 5) passed.
  - **GPL-rejection test used `surrealdb = "1"`, not `readline = "0.4"`** — the latter doesn't exist on crates.io. `surrealdb` itself is BSL but cargo-deny first rejects its transitive `ws_stream_wasm` (license `Unlicense`, not in allow-list); same outcome (`cargo deny check` exits 4), so the gate is proven. Temporary dep was reverted before commit and `Cargo.lock` returned to its pre-test state.
