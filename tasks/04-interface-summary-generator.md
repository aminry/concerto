## Goal
Stand up `scripts/regen-interfaces.sh` — the script that produces `docs/interfaces/<subsystem>.md` summaries from the canonical schema artifacts (`.proto`, `migrations/*.sql`, pub Rust traits). After this task, every later task can be verified for "did the public interface drift?" by running `regen-interfaces.sh && git diff --exit-code docs/interfaces/`. This is decision D4 in `tasks/README.md` made executable.

## Inputs to read before starting
- `tasks/README.md` §3 (D4 — schema files canonical, generated summary first to read) and §5 (verification model — silent-drift backstop).

## Scope — in
- Create `scripts/regen-interfaces.sh` (executable) that:
  1. Walks `proto/**/*.proto` and writes `docs/interfaces/proto.md` containing, per file: the package, each `message` name with its field list, and each `service` name with method signatures.
  2. Walks `crates/persist/migrations/*.sql` and writes `docs/interfaces/schema.md` containing, per migration file: the file name, each `CREATE TABLE` statement (verbatim), each `CREATE INDEX` statement.
  3. Walks `crates/*/src/api.rs` (a conventional path each crate uses for its pub-facing module — declared here as the contract) and writes `docs/interfaces/rust-api.md` containing the `pub trait` and `pub struct` declarations with their signatures.
- The script is deterministic: same inputs → byte-identical outputs. No timestamps, no random IDs.
- Each generated file starts with a header: `<!-- AUTO-GENERATED by scripts/regen-interfaces.sh — do not edit by hand. -->`.
- Create the `docs/interfaces/` directory with a placeholder `.gitkeep`.
- Generate the three interface files for the current (empty) state of the repo. They will be near-empty — that's fine.
- Add the script invocation as a CI step in `.github/workflows/ci.yml` (Linux only):
  ```yaml
  - name: Check interface summaries are up to date
    run: |
      ./scripts/regen-interfaces.sh
      git diff --exit-code docs/interfaces/
  ```

## Scope — out
- No GraphQL/OpenAPI extraction (not used in V0.1).
- No automatic linking to design-doc sections (could be a V1.0 polish task).
- No HTML rendering — pure markdown.

## Public interface this task locks
- Path: `scripts/regen-interfaces.sh` and `docs/interfaces/proto.md|schema.md|rust-api.md` are the canonical names; later tasks reference them.
- Convention: every crate's pub-facing module is at `crates/<crate>/src/api.rs`. Code that wants to be "public interface" lives in that file. Internal modules don't.
- The "no hand edits" rule: changes to `docs/interfaces/*.md` must come through regeneration.

## Implementation notes
- Implement in plain bash + `grep`/`sed`/`awk` if feasible — keeps zero deps. If parsing `.proto` correctly is too painful in bash, fall back to a small Python or Rust helper, but stay within deps that are already on a stock CI runner.
- For proto parsing, you can use `prost-build`'s own parser by writing a small Rust helper crate (`tools/regen-interfaces`) — that's cleaner than bash regex if you want to take the time. Either approach is acceptable.
- For SQL: just grep for `CREATE TABLE` / `CREATE INDEX` lines and indent them. Don't try to parse full SQL.
- For Rust traits: grep for `pub trait ` and `pub struct ` lines + their containing block. A simple awk one-liner that captures the brace-balanced region is sufficient.
- Sort outputs deterministically (by file path, then by declaration order within file).

## Verification
1. `bash -n scripts/regen-interfaces.sh` → no syntax errors.
2. `./scripts/regen-interfaces.sh` → exits 0; creates/updates `docs/interfaces/{proto,schema,rust-api}.md`.
3. `./scripts/regen-interfaces.sh && git diff --exit-code docs/interfaces/` → no diff on a clean run (deterministic).
4. Manually add a fake `pub trait Foo {}` to a crate's `src/lib.rs`; rerun the script; confirm `rust-api.md` changes. Revert the fake change.
5. `shellcheck scripts/regen-interfaces.sh` → 0 errors.
6. CI workflow includes the interface-check step and it passes on a clean PR.
